# C++ Security Manager 🛡️

Консольний додаток мовою C++ для управління користувачами та забезпечення безпеки даних. Проєкт реалізує базову систему контролю доступу (Access Control), автентифікацію та функції шифрування на основі структур (`struct`) та об'єднань.

## ⚙️ Основний функціонал (Security Features)
- **Управління акаунтами:** Додавання користувачів, відстеження їхніх ідентифікаторів (ID) та статусів блокування (Активний/Заблокований).
- **Автентифікація:** Механізм входу в систему (Login) та безпечної зміни пароля з використанням хешування.
- **Контроль доступу:** Розмежування користувачів за рівнями доступу (`accessLvl`).
- **Криптографія:** Вбудовані модулі для зашифрування та розшифрування даних користувачів.
- **Безпечний вивід:** Приховування конфіденційної інформації (хешів паролів) під час виведення загального списку користувачів.
